CAREFLOW — HEALTH CHECKUP TRACKER (ENHANCED)

HOW TO RUN IN VS CODE
1. Download and extract careflow_health_tracker_plus.zip.
2. Open VS Code > File > Open Folder, then choose `health_checkup_tracker`.
3. Open `index.html`.
4. Recommended: right-click `index.html` > Open with Live Server (install the Live Server extension if needed).
   Or double-click `index.html` in File Explorer to open it in Chrome/Edge.
5. No Python, Node.js, npm, or F5/Run button is required.

NEW DOCTOR-FRIENDLY FEATURES
- Checkup planner with overdue, due-in-7-days, later, and no-date filters
- Priority checkup queue on the dashboard
- Global patient search in the top bar
- Patient quick-view with status, condition, next checkup, contact, and care notes
- One-click scheduling from a patient's quick view or checkup list
- Scheduling a checkup updates the patient's next checkup date
- Mark an appointment as done; demo sets the next checkup 30 days later
- Optional patient phone number
- Export patient data to CSV
- Responsive layout for laptop and mobile

IMPORTANT
This is a front-end demonstration. Data is held in JavaScript memory and resets on refresh. It does not send SMS/email reminders, does not connect to a real database, and is not suitable for storing real patient health information. For a real clinic deployment, add secure authentication, database persistence, access controls, backups, and privacy/security review.
